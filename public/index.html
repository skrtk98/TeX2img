TeX2img

TeX ソースを SVG / PNG / WEBP 画像に変換します。

Ctrl / ⌘ + Enter でも変換できます。\documentclass を含まない入力は standalone クラス（amsmath, amssymb, mathtools, bm, xcolor 読み込み済み）で包みます。数式は $…$ や \[…\] で囲んでください。日本語を含む場合は自動で upLaTeX を使います。

埋め込み

    
GET で取得できる URL です。TeX ソースは圧縮して URL に含めているので、サーバー側に保存はしません。

    
ソースが長すぎるため埋め込み URL を発行できません（上限 8KB）。

    

      

        

        
      

      

        

        
      

      

        

        
      

    

  


  

    
REST API

    
TeX ソースをリクエストボディに入れて QUERY メソッドで送信します（POST でも可）。
      レスポンスの Content-Location ヘッダに、同じ画像を GET で取得できる埋め込み用 URL が入ります。

    
このデプロイ環境では、サーバーより手前のプロキシが QUERY メソッドを拒否するため
      POST で送信しています（API の挙動は同じです）。
